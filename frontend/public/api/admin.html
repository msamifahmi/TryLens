TryLens Admin

Masuk untuk mengubah harga, nama, foto, dan model 3D produk.

Kata sandi ini kamu buat sendiri di server (bernama ADMIN_TOKEN).
Lupa kata sandi atau belum punya?

Kata sandi tersimpan di file config.php di folder trylens-data pada hosting (sejajar dengan public_html), di baris adminToken. Buka File Manager hosting untuk melihat atau menggantinya. Minimal 24 karakter.
